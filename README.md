# Google Merchandise Store: Holiday Season Growth Review

**Status:** In progress (started October 2026)

A long-term analytics project using Google's public GA4 e-commerce dataset in BigQuery
(Google Merchandise Store, Nov 2020 to Jan 2021).

## Business question
What happened during the holiday season, why, and what should the store do differently next year?

## Plan
1. Business understanding and project charter
2. GA4, Search Console and Google Sheets
3. SQL in BigQuery
4. Power BI dashboard
5. Advanced SQL: sessions, funnels, cohorts
6. Python analysis
7. Statistics and A/B test design
8. Final case study

Progress updates will be added here at each milestone.
